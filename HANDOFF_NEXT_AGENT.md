# ХЕНДОФ ДЛЯ СЛЕДУЮЩЕГО АГЕНТА: ПРОЕКТ "MOUSEKIN" (МЫШОНОК В ГОРОДЕ ЧАСОВ)

## 📌 Цель задачи и контекст
Пользователь провёл аудит мобильной сборки (APK / Web) 3D-игры «Мышонок в Городе Часов» и зафиксировал критические замечания:
1. **Персонаж (Мышонок) получился не 3D, а плоским («как доска / фанера»)**: при вращении камеры видно, что это плоский многослойный 2.5D картонный сэндвич ([`src/game/Character3D.ts`](file:///Users/aego/Desktop/Projectrs/Mousekin/src/game/Character3D.ts)).
2. **Комната выглядит примитивно и стерильно**: пустая белая коробка с кубической мебелью и стандартными настенными часами.
3. **Требование пользователя**: 
   - Ничего не выдумывать с нуля! Использовать **богатую оригинальную медиабазу** (все оригинальные авторские арты, иллюстрации, звуки, озвучку на 3 языках, которые уже лежат в проекте).
   - Сделать премиальный сайт и премиальную игру с вау-эффектом.
   - Мышонок должен быть **настоящей 3D-моделью**, точной копией оригинала.

## 🚀 Чек-лист для старта работы:
1. Запустить локальный сервер `npm run dev` и проверить отображение.
2. Внедрить честную 3D-геометрию персонажа в [`Character3D.ts`](file:///Users/aego/Desktop/Projectrs/Mousekin/src/game/Character3D.ts) (убрать тонкие срезы, сделать округлое тело, объемную голову, ушки, лапки, одежду, объемный хвостик).
3. Воссоздать мансарду в [`DioramaScene.ts`](file:///Users/aego/Desktop/Projectrs/Mousekin/src/game/DioramaScene.ts) в точном соответствии с авторскими эскизами.
4. Проверить в браузере с поворотом камеры на 360°, сделать скриншоты для подтверждения отсутствия эффекта «доски».
