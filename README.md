# 🐭 Мышонок в Городе Часов (The Little Mouse in Clocktown)

Интерактивная 3D сказка-приключение по мотивам авторской иллюстрированной книги TigerCreate.

## 🌟 Особенности проекта

* **Объемная 3D-модель Мышонка из авторской акварели**:
  * Честная водонепроницаемая 3D-сетка (12 326 вершин, 24 386 граней), сгенерированная из оригинального авторского рисунка `mouse_cutout.png` алгоритмом OpenCV Distance Transform.
  * Полное сохранение авторского художественного стиля, цветовой палитры и текстуры.
  * Живая процедурная анимация дыхания, прыжок при клике/тапе, слежение взгляда за камерой.

* **Свободная камера 360°**:
  * Плавное непрерывное орбитальное вращение вокруг сцены без упоров и ограничений.

* **5 глав интерактивной истории (3D Diorama Stages)**:
  1. **🛏️ Спальня-мансарда (Лето)**: скошенный потолок, деревянные балки, авторская кровать со звездой и Сатурном (`Bed.png`), фиолетовый космический будильник (`Alarm.png`), открывающееся мансардное окно с видом на Город Часов (`ios111.jpg`).
  2. **❄️ Зимнее пробуждение**: зимняя атмосфера, вращение стрелок будильника и перемотка времени.
  3. **🍂 Осенний вечер**: золотистый свет, каминный уют и листопад.
  4. **☁️ Полёт в небесах**: Мышонок парит на пушистом облаке над панорамой Города Часов, парящие интерактивные золотые шестерёнки.
  5. **🚲 Времясипед**: старинные улицы Города Часов (`Town_20.png`), мостовая и двухколесный латунный Времясипед.
  6. **🐌 Архив и финал**: встреча с Улиткой Совершенства Матильдой (`leftsnail.png`), пушистый Кот Мартин (`WoolCat1.png`), летающие страницы факса (`pergament.png`) и праздничный салют конфетти!

* **Аутентичная озвучка на 3 языках**:
  * Оригинальные аудиодорожки сказки на русском (`ru`), английском (`en`) и немецком (`de`) языках.
  * Синхронизированные субтитры, звуки завода пружин, мурлыканья и шестерёнок.

## 🚀 Запуск и разработка

```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev

# Продакшн сборка (TypeScript + Vite)
npm run build
```
